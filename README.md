## Investigación Autónoma sobre Pygame

### 1. ¿Qué es Pygame y para qué se utiliza?
Pygame es un conjunto de módulos de código abierto para Python orientados al desarrollo de videojuegos y aplicaciones multimedia en 2D. Facilita la gestión de gráficos, sonido, teclado, ratón y controladores de joystick de forma sencilla y eficiente.

### 2. ¿Cómo se relaciona Pygame con los temas vistos en clase?
* **Ciclos (Loops):** Utiliza un bucle principal (*game loop*) que se ejecuta constantemente para actualizar la lógica, procesar entradas y renderizar gráficos frame por frame.
* **Eventos:** Emplea sistemas de control de eventos para detectar pulsaciones de teclas o el cierre de ventanas.
* **Estructuras de Datos:** Utiliza listas, tuplas y diccionarios para administrar posiciones de objetos, estados del juego y colisiones.
* **Funcionalidad Modular:** Organiza el código mediante funciones y clases para separar las físicas, el renderizado y la lógica.

### 3. ¿Qué significa que Pygame permite "tomar mucho o poco" de la librería?
Significa que no impone una estructura rígida ni un motor de juego predeterminado. Al ser una librería de bajo nivel construida sobre SDL, el programador tiene la libertad de utilizar únicamente las funciones que necesita o construir toda la arquitectura del juego desde cero.
